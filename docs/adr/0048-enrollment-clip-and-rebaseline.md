# 0048. enrollment 클립 + 측정 로직 변경 시 재기준선

- Status: Accepted
- Date: 2026-06-13
- Related: #523 (마스터), #524
- Tags: insight, statistics, process

## Context

n=1 자기 실험에서 "검증된 패턴"은 신뢰의 단위다. 측정 타당성이 흔들리면 그 위에 쌓는 상위 해석(세운·대운 가중치, #523 마스터)도 같이 흔들린다. 상위 단위 확장에 앞서 검증 엔진의 두 구조적 허점을 닫아야 했다.

### 1. sticky confirmed의 측정 기준 동결

확정(`status='confirmed'`) 링크는 sticky다 — 정기 주간 검증(`verifyUserLinks`)이 `status='active'` 링크만 로드하므로 한번 승격되면 재검정되지 않는다(ADR-0034 e-value 게이트의 optional-stopping 안전성 설계). 그러나 측정 구간 정의가 더 정밀해져도(데이터-존재 윈도우 ADR-0044 등) **이전 기준으로 승격된 등급이 동결**된다. 측정 로직이 바뀌면 기존 등급도 새 기준으로 한 번은 재평가되어야 한다.

### 2. 발굴-사육 (double dipping)

발굴(데이터 주도로 가설을 고르는 과정)·LLM 제안 출신 링크가 **자기를 선택한 데이터 구간을 그대로 포함**해 평가되면, 선택 시점까지의 우연이 효과·증거값(e-value)에 반영된다. e-value의 anytime-valid 보증은 가설이 데이터와 독립으로 고정된 뒤부터 검정할 때만 성립한다 — 같은 데이터로 가설을 고르면 그 보증이 깨진다. 현재 피해는 작지만(발굴 승인이 누적되기 전인 지금이 가장 싸게 고치는 시점), 시간이 갈수록 확정 공급원이 발굴로 이동한다.

추가로, 실데이터 구간이 짧은 신호는 off-day 대조에서 빈 과거가 분모를 비정상 확대해 효과크기를 부풀린다(ADR-0044 데이터-존재 윈도우가 1차 교정). 단 그 코드 머지 이전에 승격된 등급은 교정 전 산출물이라, 위 1과 합쳐져 "교정 이전 측정 위에서 굳은 확정"이 남는다.

## Decision

### D1 — enrollment 클립 (선택 편향 차단)

`discovery`/`llm` source 링크의 검정 시퀀스를 **`created_at`(KST) 다음 날부터**로 한정한다(`enrollmentStart`). `manual`(카탈로그 = 선험 가설) 링크는 선택 과정이 없으므로 전체 데이터-존재 윈도우를 유지한다.

```
windowStart = max(시드 데이터-존재 시작, 신호 데이터-존재 시작, enrollment 시작)
```

클립된 윈도우 시작은 `test_detail.window_start`에 영속해 관측 가능하게 한다. 발굴 전용 4번째 BH 가족은 만들지 않는다 — 사전등록된 가족 체계 변경이 더 큰 위반이고, 클립 후 각 링크가 자기 윈도우에서 marginally valid하면 가족별 BH는 유효하다.

### D2 — 측정 로직 변경 시 재기준선 (sticky 유지)

confirmed sticky는 **유지**한다(1년 미만 데이터에서 decay 검출력이 없어 별도 decay 모니터링·reaper는 만들지 않는다). 대신 **측정 로직이 바뀌면** 1회성 재기준선 스크립트(`scripts/rebaseline-pattern-links.ts`)로 confirmed를 active로 강등한 뒤 전체를 새 기준으로 강제 재검증한다. 같은 게이트(q + effect + nActive + e≥1/α)를 통과하면 자동 재확정된다. 운영 트리거·절차·검증 쿼리는 `docs/ops/verification-rebaseline.md`.

재기준선 시 사용자에게 정직 공지 카드를 보낸다 — **강등은 낙인이 아니라 측정 정확도의 결과이며 기준은 불변**, 데이터 쌓이면 같은 기준으로 재승격됨을 명시한다.

## Alternatives considered

### A. 발굴 전용 4번째 BH 가족 신설

- 장점: 발굴 출신 가설의 다중성을 가족 수준에서 격리.
- 단점: 사전등록된 가족 체계(ADR-0037) 변경.
- 기각 이유: 클립 후 marginal validity로 충분. 가족 체계 변경이 더 큰 사전등록 위반.

### B. confirmed decay 모니터링 (별도 e-프로세스 / CUSUM / reaper)

- 장점: 확정 등급의 시간적 퇴화를 상시 감시.
- 단점: 1년 미만·단일 생활국면 데이터에서 검출력이 없어 노이즈만 생성.
- 기각 이유(보류): re-baseline 운영 절차로 갈음. **재논의 트리거: 데이터 18개월+**.

### C. (선택) enrollment 클립 + 1회성 re-baseline + sticky 유지

- 장점: 선택 편향 제거 + 측정 로직 변경의 소급 경로 확보 + 운영 단순.
- 단점: 재기준선은 수동 트리거(자동화 안 함) — 측정 로직 변경 머지 시 누락 위험은 운영 문서로 방어.

## Consequences

### 장점

- 발굴 출신 가설이 등록 이후 구간에서만 평가되어 anytime-valid 보증이 복원된다.
- 측정 로직 변경이 기존 확정 등급에 소급되는 운영 경로가 생긴다.
- 강등을 정직하게 안내해 "검증됨" 라벨의 신뢰가 측정 타당성과 일관된다.

### 단점 / 제약

- 재기준선 직후 verified tier가 **일시 공백**일 수 있다(교정 이전 측정 위에서 승격됐던 등급이 내려가면 한동안 emerging 기반 "탐색적"). 기능적으로는 정상(정직한 상태)이나 체감상 후퇴로 보일 수 있어 공지 카드가 선제 설명한다.
- **출력 연속성(D8)**: 공백기에도 데일리·주간·상위 기간 카드는 계속 발송된다 — verified는 그중 한 층일 뿐.
- 클립 후 발현이 드문 발굴 링크는 무기한 active로 가족 m만 채울 수 있다(알려진 동작 — reaper 안 만듦). 주간 로그의 가족별 링크 수로 관측한다.

### 후속 작업

- [ ] Phase 1(가중치 집계 레이어)이 재기준선된 confirmed + active를 입력으로 사용.
- [ ] 측정 로직 변경 PR마다 `docs/ops/verification-rebaseline.md`의 재기준선 트리거 점검.
