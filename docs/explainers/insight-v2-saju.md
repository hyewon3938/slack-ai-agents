# 사주 부록 — 시드 출처로서의 사주 7종

> 이 문서는 [프로액티브 인사이트 v2 메인 explainer](insight-v2.md)의 부록이다. 메인은 "개인 라이프 패턴 발견 시스템"을 다섯 개의 핵심 개념(시드·매트릭·매칭·가설·검증)으로 설명한다. 이 부록은 그 안에서 **시드 출처 중 하나인 사주 7종**이 어떻게 정의되는지 깊게 풀어 쓴다.

---

## 0. 이 부록은 누구를 위한 것인가

- 메인 explainer를 다 읽은 뒤, "사주 시드가 구체적으로 무엇인지" 더 보고 싶은 사람
- 사주를 모르는 사람도 따라올 수 있게 미니 101 포함 — 다만 이건 **사주 입문서가 아니다**. 이 시스템이 사주를 어떻게 다루는지 따라가기 위한 최소 사전이다.
- 사주를 안 믿거나 관심 없는 사람은 메인 explainer만 읽으면 된다. 이 부록은 건너뛰어도 시스템 이해에 부족함 없음.

| 丁 | 정 | 화 | 음 |

| 己 | 기 | 토 | 음 |

**읽는 법**: 흔히 띠로 알려진 12동물이 지지. 오행 × 음양 + 동물의 3축. 사계(辰未戌丑)는 토에 속한다.

### 1-3. 오행 상생상극

```
       목(木)
      ↗      ↘
   수(水)    화(火)
   ↑    ↘  ↗    ↓
   ↑      ✕      ↓
   ↑    ↗  ↘    ↓
   금(金) ← 토(土)

  ──→ 상생 (다음 오행을 낳음)
  ──✕ 상극 (다음 오행을 누름)
```

| 관계 | 흐름 |
|---|---|
| 상생 | 목 → 화 → 토 → 금 → 수 → 목 (낳는 순서) |
| 상극 | 목 → 토 → 수 → 화 → 금 → 목 (누르는 순서) |

### 1-4. 십성 10개

본인의 **일간**(태어난 날의 천간 1자)을 기준으로 다른 글자와의 관계를 5쌍(음양 합쳐 10종)으로 분류.

| 십성 | 관계 (한 줄) |
|---|---|
| 비견 | 같은 오행 같은 음양 (형제·동료) |
| 겁재 | 같은 오행 다른 음양 (경쟁자) |
| 식신 | 일간이 생하는 오행, 같은 음양 (표현·산출) |
| 상관 | 일간이 생하는 오행, 다른 음양 (창의·반항) |
| 편재 | 일간이 극하는 오행, 같은 음양 (큰 재물·외부 자원) |
| 정재 | 일간이 극하는 오행, 다른 음양 (안정 재물·근로 소득) |
| 편관 | 일간을 극하는 오행, 같은 음양 (압박·권력) |
| 정관 | 일간을 극하는 오행, 다른 음양 (안정 권위·규범) |
| 편인 | 일간을 생하는 오행, 같은 음양 (특이 지원·간섭) |
| 정인 | 일간을 생하는 오행, 다른 음양 (보살핌·학문) |

> 한 줄 의미는 일반 통념. 이 시스템은 이 의미를 그대로 채택하지 않고, 각 십성이 들어오는 날의 사용자 outcome 분포를 데이터로 측정한다.

### 1-5. 12운성

본인 일간을 기준으로 지지 12개에 부여되는 생애 곡선. 어떤 지지가 일간에게 "기운이 살아 있는 시기"인지 "잠들어 있는 시기"인지를 나타냄.

```
태 → 양 → 장생 → 목욕 → 관대 → 건록 → 제왕
                                          ↓
묘 ← 절 ← 사 ← 병 ← 쇠 ←────────────────────
```

| 12운성 | 한 줄 의미 |
|---|---|
| 태(胎) | 생명의 시작, 형태 없음 |
| 양(養) | 자라기 위한 보호 단계 |
| 장생(長生) | 새로 태어남, 신선한 시작 |
| 목욕(沐浴) | 정리·세정, 변화 직전 |
| 관대(冠帶) | 의관을 갖춤, 외형 형성 |
| 건록(建祿) | 자립, 직장 |
| 제왕(帝旺) | 절정의 기운 |
| 쇠(衰) | 절정 이후 내림 |
| 병(病) | 기운이 약해짐 |
| 사(死) | 기운이 머무름 |
| 묘(墓) | 잠듦, 내면화 |
| 절(絶) | 단절, 새로 시작 직전 |

### 1-6. 본인 사주 = 4기둥 8글자 + 운(運)

사주의 "사주(四柱)"는 네 기둥. 태어난 **년·월·일·시** 각각에 천간 1자 + 지지 1자가 붙어 총 8글자.

```
            년주    월주    일주    시주
천간       □     □     ★     □       ← ★이 일간 (본인 기준점)
지지       □     □     □     □
```

이 8글자가 **원국**(natal chart). 변하지 않는다.

이 위에 시간 단위로 운이 흐른다:

| 운 레벨 | 단위 | 변동 주기 |
|---|---|---|
| 대운 | 천간 1자 + 지지 1자 | 10년 |
| 세운 | 천간 1자 + 지지 1자 | 1년 |
| 월운 | 천간 1자 + 지지 1자 | 약 1개월 (24절기 기준) |
| 일운 | 천간 1자 + 지지 1자 | 1일 |

**대운**은 출생 시각·성별에 따라 시작 나이와 흐름 방향이 결정된다.

## 2. 운 레벨 차원

이 시스템은 **5개 운 레벨**을 동시에 다룬다. 시드는 "어느 운 레벨에서 발현되는가"를 명시한다.

```
┌─────────────────────────────────────────────────┐
│  원국 (natal) — 변하지 않음                      │
│   천간 4 + 지지 4 = 8자                          │
└─────────────────────────────────────────────────┘
            │
┌───────────┴─────────────────────────────────────┐
│  대운 (10년) — 천간 1 + 지지 1                   │
└─────────────────────────────────────────────────┘
            │
┌───────────┴─────────────────────────────────────┐
│  세운 (1년) — 천간 1 + 지지 1                    │
└─────────────────────────────────────────────────┘
            │
┌───────────┴─────────────────────────────────────┐
│  월운 (약 1개월) — 천간 1 + 지지 1               │
└─────────────────────────────────────────────────┘
            │
┌───────────┴─────────────────────────────────────┐
│  일운 (1일) — 천간 1 + 지지 1                    │
│   ★ 매일 07:00 매칭 cron의 주된 평가 대상         │
└─────────────────────────────────────────────────┘
```

`pattern_catalog.pillar_level` 컬럼이 이 5개 + 누적(cumulative)을 enum으로 갖는다 (ADR-0028).

- 매일 평가는 주로 **일운** 차원에서 일어난다.
- **누적**(cumulative)은 별도 — 다음 §4에서 설명.

## 3. 시드 8종 중 사주 일운 6종 상세

`pattern_catalog.trigger_target_type`은 8종 enum:

```
stem · branch · ganji · element_density · sibiunsung · relation   ← 사주 일운 6종 (이 부록 §3)
cumulative_pillar_count                                           ← 사주 누적 1종 (§4)
life_signal                                                       ← 라이프 1종 (메인 §5)
```

사주 계열은 7종(일운 6종 + 누적 1종), 라이프가 1종이다. 이 부록은 일운 6종을 §3에서, 누적 1종을 §4에서 다룬다. `life_signal`은 메인 explainer §5에서 설명.

### 3-1. stem (천간)

- **의미**: 일운의 천간이 본인 사주의 특정 글자
- **trigger 예시**: 일운 천간 = 갑(甲)인 날
- **시드 수**: 12
- **trigger 평가**: 오늘 일운 천간 SQL 추출 → `trigger_target` 문자열과 비교
- **trigger_aux**: 없음

```sql
-- trigger 평가 (개념 표현)
SELECT day_pillar_stem(today)  =  pattern_catalog.trigger_target
```

### 3-2. branch (지지)

- **의미**: 일운의 지지가 본인 사주의 특정 글자
- **trigger 예시**: 일운 지지 = 오(午)인 날
- **시드 수**: 15
- **통합 시드**: 본인 일지와 같은 지지가 일운에 들어오는 날을 통째로 묶은 시드 1개 — 본인 일지 종류에 무관하게 evaluation 가능
- **trigger_aux**: 단일은 없음, 통합은 `{"mode": "match_day_branch"}`

### 3-3. ganji (60갑자)

- **의미**: 일운 천간 + 지지 조합(60갑자) 1개와 일치
- **trigger 예시**: 일운 = 갑오(甲午)인 날
- **시드 수**: 60
- **참고**: 본인 사주 4기둥 중 한 기둥과 일치하는 갑자는 시드로 따로 강조되지 않는다 — 모든 60갑자 시드가 동등하게 평가됨. "본인 일주와 같은 갑자가 일운에 들어오는 날" 같은 직관은 시드 description에 박혀 있고 LLM 매트릭 제안 단계에서 활용됨.

### 3-4. element_density (오행 밀도)

본인 사주 8자 + 일운 2자 = 총 **10자** 중 특정 오행이 N개 이상(또는 이하)인 날.

- **의미**: 오행 비율 임계치 트리거
- **trigger 예시**: 10자 중 토 오행이 5개 이상인 날
- **시드 수**: 10
- **trigger_aux 표준**:
  ```json
  {"element": "화", "mode": "over"}    // 특정 오행 N개 이상
  {"element": "화", "mode": "lack"}    // 특정 오행 N개 이하 (예: 0\~1)
  ```

본인 원국 8자는 고정이므로 element_density는 일운 2자에 따라 결정된다. 어떤 오행이 본인에게 부족(lack)한지는 사주 도구 안에서 결정론적으로 계산된다.

### 3-5. sibiunsung (12운성)

본인 **일간**을 기준으로 일운 **지지**의 12운성 분류.

- **의미**: 일운 지지가 본인 일간에게 어떤 생애 곡선 단계인지
- **trigger 예시**: 본인 일간이 갑(甲) → 일운 지지가 오(午) → 12운성 = 사지(死). "사지가 들어오는 날"
- **시드 수**: 12
- **trigger_aux 표준**: `{"name": "장생"}` 등 12운성 이름 1개

12운성 lookup table(`sibiunsung_lookup`)이 천간 10 × 지지 12 = 120개 매핑을 보관. 본인 일간이 결정되면 일운 지지에 대한 12운성이 한 번 lookup으로 결정.

### 3-6. relation (지지 관계)

본인 사주 4지지(년·월·일·시) 중 어느 한 자리와 일운 지지 사이의 **관계**.

- **의미**: 본인 지지와 일운 지지가 합·충·형·파·해·원진 등 관계를 맺는 날
- **trigger 예시**: 본인 일지 = 진(辰), 일운 지지 = 술(戌) → "진술충" 발현
- **시드 수**: 72 (관계 종류 × 본인 자리 위치)
- **trigger_aux 표준**:
  ```json
  {"position": "day", "relation": "충", "pair": ["진", "술"]}
  ```

| 관계 | 한 줄 의미 (일반 통념) |
|---|---|
| 합(合) | 결합·끌어당김. 육합·삼합·방합 등 세부 분류 |
| 충(沖) | 충돌·흔들림 |
| 형(刑) | 마찰·고생 |
| 파(破) | 깨짐 |
| 해(害) | 방해 |
| 원진 | 미묘한 갈등 |

`branch_relations` 테이블에 약 61개 매핑이 보관됨. 본인 지지 × 일운 지지에 대해 모든 가능한 관계가 사전 계산되어 있다.

> 모든 관계의 "통념적 의미"는 그대로 검증 대상이 아니다. 이 시스템은 각 관계가 들어오는 날 사용자 outcome 분포를 측정해 통계로 가설을 잡을 뿐.

## 4. cumulative_pillar_count 풀셋 (N=1..5)

위 6종은 일운 차원에서 평가된다. **누적(cumulative)** 차원은 따로 있다.

**아이디어**: 5개 운 레벨(원국 + 대운 + 세운 + 월운 + 일운) 중 특정 오행 또는 특정 십성이 **몇 개 레벨에 발현**됐는지 카운트.

```
          원국  대운  세운  월운  일운
화 오행:   2자   0자   1자   1자   1자    → 발현 레벨 4개 (원국·세운·월운·일운)
                                          → N=4 임계 통과
```

`cumulative_pillar_count` trigger는 N=1\~5 임계치별로 별도 시드를 둔다. 어느 N이 의미 있는 임계인지는 데이터가 결정한다 (ADR-0028).

| 시드 예 | 의미 |
|---|---|
| `pool_화_오행_누적_N1` | 화 오행이 5개 레벨 중 1개 이상에 발현된 날 |
| `pool_화_오행_누적_N3` | 화 오행이 5개 레벨 중 3개 이상에 발현된 날 |
| `pool_화_오행_누적_N5` | 화 오행이 5개 레벨 전부에 발현된 날 |

매주 월요일 **09:15** 분포 분석 cron이 N별 hit-rate 분포를 한 줄로 노출한다. 임계치를 임의로 정하지 않고 데이터로 결정한다는 v2 헌장 "임의값 박지 않기" 적용 사례.
