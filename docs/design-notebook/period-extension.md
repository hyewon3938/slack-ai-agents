# 세운·대운 확장 + 검증 엔진 교정 — 일 단위 실증을 상위 주기 해석으로

> 마스터 이슈: [#523](https://github.com/hyewon3938/slack-ai-agents/issues/523)
> 시작: 2026-06-13
> 상태: **Phase 0\~3 전부 머지 완료 — 마스터 #523 CLOSE.** 검증가능성 사다리 4층 완결(Phase 3 예측 장부 = [#531](https://github.com/hyewon3938/slack-ai-agents/issues/531))
> 관계: [#408](https://github.com/hyewon3938/slack-ai-agents/issues/408)(월/세/대운)의 5-B를 구체화. 세운·대운 직접 통계검증 영구 기각은 #408 선언 유지.

## 개요

일운(일 단위) 검증 엔진이 학습한 개인화 작용 — "이 사람은 어떤 십성·오행에 어떻게 반응하는가" — 을 월운·세운·대운 같은 **상위 주기 해석**으로 확장한다.

단, 적대적 감사 결과 **기존 엔진을 교정하지 않고는 확장이 불가**했다: 가중치의 원료가 측정 아티팩트 위에 있었다(데이터-존재 윈도우 이전 코드 산출물, 발굴-사육 구멍). 그래서 이 마스터는 **교정을 선행 분리**(Phase 0)하고, 그 위에 집계 레이어(Phase 1) → 해석 엔진(Phase 2) → 예측 장부(Phase 3)를 쌓는다.

프로젝트 본질은 **n=1 자기 실험**이다. "사주를 믿든 안 믿든 데이터로 측정·검증한다"가 논리이고, 검증된 패턴의 예측이 실제로 맞을 때 목적을 달성한다. 따라서 이 확장의 가장 큰 인식론적 리스크는 "**검증할 수 없는 것을 검증된 것처럼 말하는 것**"이며, 핵심 원칙 전체가 그 방어선이다.

## 핵심 원칙 — 자체 헌장 (변경 불가, 변경 시 ADR)

### 1. 검증가능성 사다리 (이 확장의 헌법, ADR-0050)

단위가 커질수록 표본이 기하급수로 줄어 통계 확정 가능성이 떨어진다. 각 층의 **지위를 명시적으로 다르게** 두고, 출력은 자기 층의 지위를 항상 라벨로 동반한다.

| 층 | 단위 | 지위 | 메커니즘 |
|---|---|---|---|
| 일운 | 일 | **실증** | off-day 2×2 + e-value + 가족 BH (Phase 0 교정 후) |
| 월운 | 절기월 | **축적-실증** | 예측 장부(생성→채점) + 누적 기술통계. 월 단위 e-게이트 금지(월 n이 수년간 한 자릿수) |
| 세운 | 입춘년 | **장부 한정 약실증** | 입춘 예측 → 다음 입춘 채점. 수명 내 n=1\~2 — 통계 확정 영구 불가. 1차 가치는 확증편향 차단 규율 |
| 대운 | 10년 | **비실증 추론 레이어** | 검증 불가 명시. 가중치 매트릭스 + 교과서 일반론의 라벨 분리 서사만 |

**전이 가설**(일 단위 십성·오행 반응이 상위 단위에서 같은 방향 배경 기류로 보존된다)은 **미검증 가정**이다. 모든 상위 단위 출력에 라벨로 따라다니고, 예측 장부가 천천히 채점하는 대상이 바로 이 가설이다. 명리 내부에서도 운-원국 상호작용으로 방향이 뒤집힐 수 있다는 반론이 있어, 해석 레이어는 이를 hedge로 언급할 수 있다(통계 주장은 금지).

### 2. 출력 연속성 (검증은 백그라운드, 출력은 항상)

검증 주기가 길어져도 사용자는 해석·경향 리포트를 계속 받아야 한다. 모든 주기 카드(월운/세운/장부)는 **측정 증거가 0이어도 발송**된다 — 교과서 일반론(미검증 라벨) + 누적 기술통계 + emerging 경향("이런 게 보이는데 검증중") + 예측 안 하는 사유로 채운다. **침묵 금지, 단 무증거를 증거처럼 말하기도 금지** — 증거가 얇다는 사실 자체가 콘텐츠다. (사용자 원칙으로 이 마스터뿐 아니라 모든 도메인 출력에 적용된다.)

### 3. 측정 무결성 — 선택 편향과 측정 아티팩트 차단

- **enrollment 클립**(ADR-0048): 발굴/LLM 경유로 선택된 가설은 **선택 시점 이후 데이터로만** 검정(e-value "test from now" 정신). 카탈로그(선험) 가설은 전체 윈도우 유지.
- **측정 로직 변경 시 재기준선**(ADR-0048): 측정 코드가 바뀌면 과거 확정도 강제 재검증한다. confirmed sticky는 유지하되, 재기준선이 그 우회로. 1년 미만 데이터에서 검출력 없는 decay 모니터링은 만들지 않는다.
- **데이터-존재 윈도우**(ADR-0044): 검정 윈도우는 데이터가 실제 존재하는 구간으로 한정(없는 날을 "fail"로 세지 않음).

### 4. 가중치 입력의 보수성 — winner's curse 차단

가중치 집계의 효과 입력은 raw rate ratio가 아니라 **shrunk 추정**(posterior_p / rate_off, ADR-0049)을 쓴다. 교란으로 explained_away된 링크는 제외, attenuated는 조정 RR과 min. 선택된 링크의 과대 효과가 상위 단위 외삽으로 증폭되는 걸 막는다.

### 5. 이중계산 구조적 차단 — 한 증거는 한 번만

집계 축은 글자→십성→그룹(+오행 별칭) **단일 레벨 resolution** + element_band(강 방향만) 별도 축이다(ADR-0049). 원천 기여는 링크당 정확히 1셀, 상위 레벨은 결정론 롤업, 읽기는 한 레벨에서 정지(두 레벨 합산 금지).

### 6. 결정론은 얕게, 해석은 깊게 (ADR-0038 계승)

사주 글자·십성·합충 도출은 결정론 코드가, 서사는 LLM이 담당한다. LLM에는 구조화 payload만 주고, **측정 기반 셀과 교과서 일반론 셀을 분리 발화**시킨다.

### 7. 영구 기각 목록 (재논의 금지 — 트리거 명시분만)

세운·대운 직접 통계검증 / 과거 대운 retro-fitting(확증편향 기계) / 월운 e-게이트 / 합충 가중치 편입 / e-value merging / 다변량 회귀 / decay reaper / 4번째 BH 가족 신설 / 장부의 Brier·확률점수. 근거는 ADR-0050 + 마스터 계획서 §7.

## Phase 0 — 측정 교정 (완료)

적대적 감사가 두 가지를 드러냈다. ① 유일한 확정 패턴이 **측정 아티팩트** 위에서 승격됐다 — 실데이터가 얇은데 데이터-존재 윈도우 이전 코드가 "데이터 없음"을 대량의 fail로 집계한 위에서 통과했고, confirmed가 sticky라 영구 미재심이었다. ② **발굴-사육 구멍** — 발굴 경유 가설이 자기를 뽑은 데이터로 e/q를 축적하는 구조(선택 편향).

처방: enrollment 클립(ADR-0048) + 일회성 재기준선(확정 강등 포함 전 링크 강제 재검증) + "측정 로직 변경 시 재기준선" 운영 절차 문서화(`docs/ops/verification-rebaseline.md`) + 정직 공지 카드. 재기준선 실행 후 README/explainer 수치를 실측값으로 갱신했다.

결과적으로 확정 패턴은 실데이터 구간 기준 판단 보류로 조정됐고(강등은 낙인이 아님 — 기준은 동일, 데이터가 쌓이면 재승격), prod 수치가 신뢰 가능해졌다. 한동안 모든 예측이 emerging 기반 "탐색적" 라벨일 수 있으나 이는 **정직한 상태**이며, 출력 연속성 원칙(헌장 2)이 공백기에도 카드가 끊기지 않게 보장한다.

## Phase 1 — 개인화 가중치 집계 (완료)

교정된 링크 증거(확정·검증중 pattern_links)를 사주 축으로 모아 개인화 프로필 `saju_response_profile`(파생 테이블, pattern_links에서 재생성 가능)을 만든다. Phase 2·3가 기간 pillar에 조인할 원료다.

핵심 난점은 **이중계산 방지**였다(헌장 5). 링크당 정확히 1 source 셀에 기여하고, 상위 레벨(십성·그룹)은 결정론 롤업, 읽기는 단일 레벨 resolution(`resolveHierarchyCell`/`resolveElementBandCell`)으로 한 레벨에서 정지한다. within-level 불변식을 단위 테스트로 고정했다.

설계 대비 보정 한 건: char 레벨을 `char_stem`/`char_branch`로 분리했다. 한글 동음이의(천간 辛 vs 지지 申이 같은 '신')가 서로 다른 십성으로 가는데, 단일 'char' 축으로 병합하면 롤업 불변식이 깨진다 — 테스트가 잡아낸 실버그. 상세는 [insight 도메인 §37](../domains/insight.md) + ADR-0049.

## Phase 2 — 기간 해석 엔진 + 주기 리포트 + fast path (완료, #529)

일운 집계 레이어를 월운·세운·대운 해석으로 잇는다. 결정론 도출(기간 pillar → 십성·오행·합충) → 개인화 프로필 조인으로 `{measuredCells, textbookCells, descriptiveStats}` payload → LLM 서사(측정/교과서 분리 발화 + 전이 가설 hedge) → 결정론 렌더(cron·fast path 공용). 절기 전환·입춘·대운 전환을 감지하는 전용 데일리 슬롯이 카드를 발송하고, 정확 일치 조회 명령(`^월운$`/`^세운$`/`^대운$`)이 저장된 해석을 LLM 없이 즉시 렌더한다(접미형 자연어 조회는 기존 교과서 레이어로 하위 호환).

부수 효과로 만세력 절기 테이블의 **기존 시한폭탄**(미연장 시 특정 연도부터 일일 매칭 전체 throw)을 해소한다 — 단, 테이블 구동 방식의 본질상 폭탄은 사라지지 않고 만료 연도가 뒤로 이동하므로 갱신 절차를 명시한다.

### 구현 회고

**절기 데이터 — 추측 금지, 교차검증으로 확보.** 시한폭탄(미연장 시 해당 연도부터 월주/년주 전체 throw)을 해소하려고 2029\~2033 절기 60개(5개년 × 월 전환 12절기)를 넣어야 했다. 절기는 천문 시각이라 추측하면 그 연도 월주가 통째로 어긋난다. 절차: ① 절기 시각표(NASA DE441 기반)를 연도별로 받아 ② **KST(UTC+9)로 환산** — 출처가 CST(UTC+8)라 +1시간, 23시 이후면 날짜가 익일로 넘어간다(2031 입동이 정확히 그 케이스: 23:05 CST → KST 11-08) ③ Wikipedia의 독립 UTC 표(입춘·입동 일부 연도)와 분(分) 단위로 일치 확인 ④ 결정적 검증으로 **2028년 행(기존 테이블에 이미 있던)을 같은 출처에서 다시 받아 11개 절기가 전부 일치**함을 확인 → 같은 데이터셋임을 입증하고 2029\~2033을 신뢰. 2025 입춘이 02-03인 것도(타임존 환산이 날짜를 가르는 실제 사례) calibration에 썼다. 폭탄은 사라지지 않고 **2034-01로 이동** — 테이블 구동 방식의 본질이라 갱신 절차를 ADR-0050에 명시.

**입춘 double-trigger — else-if가 아니라 독립 검사.** 입춘은 인월 전환(절기 전환)이자 새해 시작이라 **월운과 세운이 같은 날 동시 발생**한다. 게이트를 else-if로 짜면 둘 중 하나만 발사된다. `decidePeriodTriggers`를 3개 독립 검사(절기/입춘/대운)로 두고 각각 트리거를 배열에 push하게 했다. 테스트로 입춘날 [wolun, seun] 2개, (입춘+대운 시작 겹치는 날) 3개까지 고정.

**대운 "정보 없어" 안내는 cron이 아니라 fast path로.** 만 나이는 단조 증가 → 대운 전환은 항상 null→pillar 또는 pillar→pillar(결과가 전부 non-null)다. nonnull→null 전환은 발생할 수 없어 cron의 대운 카드는 항상 유효 pillar를 가진다. "대운 정보가 아직 없어"는 사용자가 `대운`을 조회했는데 저장 행이 없을 때의 fast path 책임으로 옮겼다 — cron이 매일 안내 카드를 쏘면 평일 no-op 원칙이 깨지기 때문.

**fast path 평가 순서가 동작을 가른다.** 기존 `MONTHLY_FORTUNE_RE` 등은 접두·접미가 전부 optional이라 맨말 "월운"도 매칭한다. 그래서 정확일치(`^월운$`)를 **기존 regex보다 먼저** 평가해야 "월운"이 period_interpretations(신규)로, "월운 보여줘"·"이번 달 월운"이 fortune_analyses(교과서 레이어, 하위 호환)로 갈린다. 순서 한 줄이 두 경로를 가른다 — 코드와 ADR에 ⚠️로 박아둠.

**measured=0 일급 경로(헌장 2).** 렌더 함수가 측정 셀 0건일 때도 빈 카드를 내지 않고 "측정된 반응 — 아직 없어" 명시 + 교과서 일반론 + 누적 기술통계 + 사다리 지위 footer로 채운다. 단위 테스트로 measured=0 케이스에 측정/교과서/사다리 블록이 모두 있고 빈 카드가 아님을 고정. 침묵 금지 + 무증거를 증거처럼 말하기 금지를 코드 경로로 강제.

**기술적 의의.** 검증할 수 없는 층(세운 n=1\~2)에서도 "검증된 척"을 구조적으로 차단하면서 출력은 끊기지 않게 하는 인식 지위의 아키텍처 — measured/textbook 분리 발화 + 전이 가설 hedge + 사다리 라벨이 모든 상위 단위 출력을 따라다닌다. 상세 판단은 [ADR-0050](../adr/0050-verifiability-ladder-and-forecast-ledger.md), 도메인 사실은 [insight 도메인 §38](../domains/insight.md).

> 예측 장부(`period_forecasts`, 마이그 091)는 Phase 3 — ADR-0050에 스키마 설계만 일괄 기록, 코드는 후속.

## Phase 3 — 예측 장부 (완료, #531) · 마스터 마지막 phase

검증할 수 없는 층(월운·세운)에 **사전등록 → 자동채점** 장부를 심는다. 통계로 확정 못 해도, 예측을 미리 박아두고 사후에 채점하면 확증편향을 차단하는 규율이 된다. 장부가 천천히 채점하는 대상은 전이 가설(일 단위 반응이 상위 주기로 보존되는가)이다.

이 phase의 헤드라인은 **자기검증 메커니즘**이다. 사용자 원칙 — "지금 완결된 메커니즘을 다 만들어두고, 시간이 흐르면 그게 스스로 검증·작동되게" — 의 정수. 생성과 채점이 모두 절기/입춘 **시간 게이트**(기존 `periodFortune` 슬롯)만으로 무인 작동하고, 멱등(재실행 안전) + baseline 등록 시 봉인 + 놓친 전환 자가 회수로 1년을 그냥 굴려도 채점 결과가 안전하게 쌓인다. 수동 트리거 0.

- **데이터 모델**(마이그 091): `period_forecasts` — 신호당 1행 정규화. ADR-0050 예시 SQL(JSONB 배열)을 정규화로 reconcile(채점 추출·dedup·멱등 INSERT의 SQL 직접 표현 — 원칙은 불변). wolun+seun만(대운 비편입).
- **예측 단위 reconcile**: 셀은 도메인 레벨, 예측 행은 신호 레벨. 한 셀의 근거 링크 중 증거 최대(발현일) 링크의 신호를 대표로, baseline은 그 링크의 발현-부재 비율(`rate_off`) 동결.
- **자기검증 5요소**: 시간 구동 / 멱등 / 자가 회수(`period_end ≤ today`) / baseline 봉인 / 결과 수동조회 없이 노출. reaper·decay 미추가(순수 이벤트 구동, D2/D7).
- **통합**: `period-forecast.ts`(생성·채점·로드) + `period-fortune.ts`(①채점 ②해석 ③생성 ④카드 장부 섹션) + 해석 렌더 `ledger?` 인자 + fast path 동봉.

### 구현 회고

**스키마 reconcile이 곧 설계.** 계획서 §6는 "신호당 1행", ADR-0050 예시 SQL은 "period당 1행 + JSONB 배열"로 갈라져 있었다. 정규화를 택하니 `UNIQUE(user, type, start, signal_id)` + dedup이 필연적으로 따라왔고, 그게 "셀은 도메인 레벨인데 행은 신호 레벨"이라는 다리(§5-A 대표 신호)를 강제했다. 두 표현이 충돌한 게 오히려 예측 단위를 명확히 했다.

**대표 신호 선택의 함정.** 측정 셀은 여러 신호를 롤업하지만 채점은 구체 시리즈(`computeSignalSeries`)가 필요하다. 그래서 셀의 `sourceLinkIds` 중 발현일(nActive) 최대 링크의 신호를 대표로 뽑되, 타이는 `min signal_id`로 결정론을 고정했다(테스트로 못박음). 카드가 보여준 "측정 셀"과 장부가 예측한 "셀"이 어긋나지 않게 `MeasuredCell`에 `sourceLinkIds`를 실어 payload를 생성의 단일 입력으로 만든 게 드리프트 0의 핵심.

**baseline = 발현-부재 비율(`rate_off`) 동결.** 신호 전체 평균 pass율이 아니라 "그 feature가 꺼졌을 때 pass율"이 전이 가설의 올바른 null이다(기간 = feature 켜진 연장 구간 → 그 pass율이 발현-부재 baseline을 넘는가). 채점 윈도우에 `baselineLeadInDays`(28) 선행을 포함해 above_avg rolling baseline을 워밍업하되, 집계는 기간 내 일자만 — 같은 이진화 정의, 다른 날짜 집합이라 비교 가능.

**자기검증을 "안 만든 것"으로 증명.** reaper도 decay 모니터도 일부러 안 넣었다. 채점을 `period_end == today`가 아니라 `<= today`로 잡으니 놓친 전환을 다음 전환이 자동 회수한다 — 별도 감시 프로세스 없이 self-heal. 멱등은 생성측(기간당 1회 가드 = baseline 동결 무결성)과 채점측(`status='open'` 가드)에 각각, no_call은 partial unique로 1행 보장. "채점 전후 baseline 불변" 불변식은 테스트로 고정했다(확증편향 차단의 구조적 증거).

**D8 no_call도 일급 경로.** 예측할 셀이 0개여도 침묵하지 않고 `no_call` 1행을 박아 "예측 안 함 + 사유"를 카드에 띄운다. 무증거를 증거처럼 말하지도, 침묵하지도 않는 출력 연속성을 코드 경로로 강제.

**순수 리팩토링으로 SignalDef 단일화.** 채점이 신호 정의를 필요로 해 `loadSignalDefsByIds`를 `pattern-verification.ts`에서 추출했다. `verifyUserLinks`가 같은 SELECT를 라벨 계산에도 쓰고 있어, SELECT를 private 헬퍼(`querySignalDefRows`) 한 곳으로 모으고 두 경로가 공유 — 검증 핫패스 동작 불변(896 테스트가 회귀 가드).

**기술적 의의.** "지금 완결된 메커니즘을 만들어두면 시간이 스스로 검증한다"를 멱등·동결·자가회수·도메인시계로 분해해, 무인으로 1년을 굴려도 장부가 오염되지 않고(틀린 장부가 아니라 빈 장부로 degrade) 결과가 쌓이는 설계. 비자명 어필은 [portfolio-candidates](../_personal/portfolio-candidates.md), 도메인 사실은 [insight §39](../domains/insight.md), 결정은 [ADR-0050](../adr/0050-verifiability-ladder-and-forecast-ledger.md).

### 마스터 완결

Phase 0(측정 교정·재기준선) → 1(개인화 가중치 집계 `saju_response_profile`) → 2(기간 해석 엔진 + 주기 리포트 + fast path) → 3(예측 장부)로 **검증가능성 사다리 4층이 완성**됐다: 일운=실증 / 월운=축적-실증 / 세운=장부 한정 약실증 / 대운=비실증 추론. 각 층은 자기 인식 지위를 라벨로 동반하고(전이 가설 hedge + 사다리 footer), 검증 불가 층에는 사전등록 장부가 확증편향 차단 규율을 무인으로 굴린다. #408 5-B(상위 주기 확장)의 구체화이자, #523 master는 이 phase 머지로 **close**.
